# Validation record

This file records executed checks; CI and release results are added after verification. The cloud execution machine is Debian 13 x64, not Ubuntu or Windows.

Local checks passed during implementation:

- TypeScript typecheck and production Electron/React/Vite build.
- Scheduler/proxy/target/settings tests: deterministic 120-second keyword rotation, fresh distinct and identical pools, retry/cancellation, failure isolation, challenge suspension, resource deferral and input validation.
- On-disk SQLite reopen, retained rankings/settings and credential-free allocation history.
- 17 real Chromium fixture tests: ten concurrent proxied contexts with cookie/local/session storage isolation, dynamic/hidden results, organic pagination, unsupported DOM, three challenge classes, actual HTTP CONNECT, scrolling/internal navigation, blocked external redirects and cleanup during stalled navigation/launch.
- Integrated four-cycle browser/controller/API/SQLite run: A → B → C → A, four separate fresh fetches, ten sessions per cycle, 80 retained rankings, and no contexts after Stop. Later aggregate checks use a six-second fixture interval to allow completed measurements under load; simulated-clock tests cover the actual 120-second example.
- Native Electron UI under Xvfb: actual Start/Pause/Resume/Stop, ten fixture sessions, twenty first-cycle rankings, screenshot preview, fresh resume fetch, settings/history after application reopen, and no renderer errors.
- Native Linux AppImage and DEB generation including the Playwright-pinned browser. Both packaged apps passed the complete desktop workflow after extraction on the cloud Debian 13 machine. Remote native-platform checks remain separate.

The versioned local measurement is in [benchmark-debian13.json](benchmark-debian13.json). Fresh capacity results are written to `test-results/capacity.json` by the current run. Fifty logical contexts were created and observed successfully on the cloud machine. Resource values, duration and Chromium provenance are regenerated by the integration suite. Aggregate RSS includes shared pages and must not be interpreted as unique physical RAM; PSS, when available, is a better estimate. The capacity suite verifies measured deferral on smaller machines and reports the active count honestly.

Native-platform CI passed on Ubuntu 22.04, Ubuntu 24.04 and Windows Server 2022 for application source commit `6dc01ae654c4ff2738f1409fa01f19e10a053a1b`: [verified run 37804543341](https://github.com/0xSkyler/DOM/actions/runs/37804543341). Each platform passed typecheck, 37 unit tests, 17 real browser tests, two controller/browser integration tests, the production build and the complete Electron desktop smoke. The desktop check includes CSV/XLSX exports, fresh proxy fetching on resume, Stop cleanup, retained settings/history and renderer isolation. Linux CI uses Xvfb and an explicit sandbox override for isolated runner QA.

Native release jobs additionally build and install/extract the actual packages and repeat the desktop smoke before publishing. Consult the [release workflow](https://github.com/0xSkyler/DOM/actions/workflows/release.yml) and [published releases](https://github.com/0xSkyler/DOM/releases) for package results; a workflow definition alone is not evidence of a published artifact.
